# Night Drive Pixel

夜の車内から見たドライブ風景を、ブラウザ上で手続き生成するピクセルアートのアニメーションです。

- `index.html` をブラウザで開くだけで動きます（ビルドや外部ライブラリは不要）
- 描画解像度は 320×180。216色パレットと Bayer ディザで減色し、拡大表示しています
- 疑似3Dの道路（カーブあり）、街灯、対向車・先行車、ビル群、デリニエーター、標識
- 天気: 自動（晴れ→小雨→嵐→晴れの約70秒サイクル）/ 晴れ / 雨 / 嵐
  - 雨粒、フロントガラスの水滴、ワイパー、濡れた路面の反射、霧、雷
- 車内: 右ハンドル、メーター、ステアリング、カーナビ風ディスプレイ、ルームミラー
- 「GIFを作る」でブラウザ内で GIF を書き出し、「動画を録画」で WebM を録画

`sample-rain.gif` は雨天で 6 秒間書き出したサンプルです。
