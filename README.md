# Pixel Scenery

ブラウザで手続き生成するピクセルアートの景色アニメーション集です。どれも HTML ファイルを開くだけで動き、GIF 書き出しと動画録画ができます。

| ファイル | 内容 |
| --- | --- |
| `index.html` | 夜のドライブ（後部座席の窓から） |
| `train.html` | レトロ電車の車窓（朝・昼・夕・夜） |
| `sea.html` | 手漕ぎボートの海（朝・昼・夕・夜） |

---

## Night Drive（index.html）

夜のドライブ中に、後部座席の窓から見える景色をブラウザで手続き生成するピクセルアートのアニメーションです。

- `index.html` をブラウザで開くだけで動きます（ビルドや外部ライブラリは不要）
- 描画解像度は 320×180。216色パレットと Bayer ディザで減色し、拡大表示しています
- 5層の視差スクロール（山並み / 遠景 / 中景 / 線路 / 近景）で、近いものほど速く流れます

## 景色（約 30〜60 秒ごとに移り変わる）
市街地・住宅街・田園・山道・トンネル・海沿い・大きな橋。
電柱と電線、自販機、カーブミラー、お地蔵さん、鳥居、電照菊のビニールハウス、灯台、漁船などが出てきます。

## イベント（ランダム）
鹿の群れの並走、キツネ、タヌキ、塀の上の猫、犬の散歩、自転車、ジョギング、
電車の追い越し／すれ違い、花火、流れ星、UFO、夏祭りの提灯、パトカー、夜間工事（誘導員）、雷。
画面の右側に、何が起きたかのログが出ます。

## 天気
自動（晴れ→雨→土砂降り→晴れの約90秒サイクル）/ 晴れ / 雨 / 嵐。
窓ガラスを後ろへ流れる水滴、雨筋、濡れた地面、雷。

## 書き出し
「GIFを作る」でブラウザ内で GIF を生成し、「動画を録画」で WebM を録画します。

`sample-country.gif`（田園・晴れ）と `sample-rain.gif`（住宅街・雨・夏祭り）がサンプルです。

## レトロ電車の車窓（train.html）
木の窓枠、白い枕カバーの青いボックスシート、網棚の麦わら帽子、揺れるつり革、天井の扇風機、窓際の冷凍みかんとラムネ。
田園・集落・鉄橋・海辺・山あいのトンネル・小さな町を走り、ときどき駅に停まります（駅名標つき）。
イベント: 踏切、犬の散歩、手を振る子ども、田んぼの農家さん、白サギ、自転車の並走、対向列車、夕方のカラス、飛行機雲、夜のホタル・花火・流れ星、釣り人。
時間帯は自動で朝→昼→夕→夜と巡ります（固定も可）。サンプル: `sample-train.gif`

## 手漕ぎボートの海（sea.html）
船首から見た一人称視点。オールで漕ぐと進み、止めると波に揺られて漂います。
イベント: 空き缶・手紙入りの瓶が流れてくる、トビウオ、カモメ（船首にとまることも）、漁船の釣り、遠くの島の焚き火、イルカ、クジラの潮吹き、クラゲ、ウミガメ、フェリー、飛行機雲、流れ星。
夜はイカ釣り漁船の漁り火、灯台、オールで光る夜光虫。サンプル: `sample-sea.gif`
