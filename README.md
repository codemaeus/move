## Night Drive（index.html）

夜のドライブ中に、後部座席の窓から見える景色をブラウザで手続き生成するピクセルアートのアニメーションです。

- `index.html` をブラウザで開くだけで動きます（ビルドや外部ライブラリは不要）
- 描画解像度は 320×180。216色パレットと Bayer ディザで減色し、拡大表示しています
- 5層の視差スクロール（山並み / 遠景 / 中景 / 線路 / 近景）で、近いものほど速く流れます

## 景色（約 30〜60 秒ごとに移り変わる）
市街地・住宅街・田園・山道・トンネル・海沿い・大きな橋。
電柱と電線、自販機、カーブミラー、お地蔵さん、鳥居、電照菊のビニールハウス、灯台、漁船などが出てきます。

## イベント（ランダム）
鹿の群れの並走、キツネ、タヌキ、塀の上の猫、犬の散歩、自転車、ジョギング、
電車の追い越し／すれ違い、花火、流れ星、UFO、夏祭りの提灯、パトカー、夜間工事（誘導員）、雷。
画面の右側に、何が起きたかのログが出ます。

## 天気
自動（晴れ→雨→土砂降り→晴れの約90秒サイクル）/ 晴れ / 雨 / 嵐。
窓ガラスを後ろへ流れる水滴、雨筋、濡れた地面、雷。

## 書き出し
「GIFを作る」でブラウザ内で GIF を生成し、「動画を録画」で WebM を録画します。

`sample-country.gif`（田園・晴れ）と `sample-rain.gif`（住宅街・雨・夏祭り）がサンプルです。

## 森の迷宮 ― 封印の主（mori.html）
レイキャスティングの一人称RPG。256×144・216色。毎回ちがう迷宮（31×31の森の迷路、北東の遺跡、広場、南東の主の間）を生成する。
- 自動プレイ: 勇者が自分で探索し（未探索の場所・宝箱・アイテム・鍵→扉→主の間）、敵を見つけると狙って撃ち、距離を取り、体力が減ると薬を飲む。主を倒すと次の迷宮へ。操作すると8秒間は手動。
- 戦闘: 魔法の矢（連射）と火球（MP4・爆発で範囲ダメージ）。敵はスライム、森狼、毒キノコ（胞子を撃つ）、骸骨の射手（矢を撃つ）、吸血コウモリ、ミミック、森の主（種の弾幕・スライム召喚・叩きつけ）。見えていなければ地形を回り込んで追ってくる。
- RPG要素: レベルと経験値、HP/MP、ゴールド、ポーション/エーテル、宝箱（ミミック入り）、女神のクリスタル（回復と復活地点）、旅の商人、妖精、木の実、狼の群れの待ち伏せ、コウモリの群れ、ミニマップ（歩いた場所だけ見える）、メッセージウィンドウ。
- 見た目: 杖・松明・火球・胞子が本物の光源として周りを照らす、ダメージ数字、被弾の赤い点滅と方向表示、画面の揺れ、ボス登場の演出、雨と雷。
- 音: 探索・戦闘・ボス・勝利で切り替わるチップチューン、各種効果音。
操作: WASD 移動 / ←→・ドラッグ 見回す / Space・クリック 撃つ / 1・2 魔法切替 / H 薬 / M 地図 / P 一時停止。スマホは画面下のボタン。サンプル: `sample-mori.gif`

## 大怪獣ザムラ ― 首都上陸（daikaiju.html）
怪獣の目線で街を壊していく一人称視点。256×144・216色。高さの違うビルを1列ずつ手前から奥へ描く「高さマップ」のレイキャスティングで、ビルの壁と屋上、道路を上から見下ろせる。
- 流れ: 夕暮れの湾から浮かび上がる（目に水が流れる）→ 港のコンテナとクレーンを越えて上陸 → 市街地で暴れる → 防衛隊（戦車・攻撃ヘリ・戦闘機・対怪獣兵器の光線砲車・防衛艦）と戦う → 宿敵の怪獣（紅蓮怪獣ゾルガ／対怪獣決戦機クロガネ）と対決 → 都心の電波塔を倒し、空へ熱線を吐いて海へ帰る → 次の街。毎回ちがう街を生成する。
- 破壊: ビルは叩くと窓ガラスと破片が飛び、上から削れ、最後は土煙を上げて崩れ落ちてがれきになり、燃え続ける。低いビルや車両は踏みつぶす。咆哮で近くの窓が割れる。電波塔やクレーンは傾いて倒れ、下の建物を巻きこむ。
- 攻撃: 爪（左右交互・斬撃の軌跡）、熱線（背中から光が上り、押している間吐き続ける）、咆哮。宿敵とは熱線どうしの押し合い、組み合い、投げ飛ばしがある。
- 臨場感: 一歩ごとの地響きと視点の沈み込み、爆発・倒壊・被弾での画面の揺れ、見下ろす・見上げる視点、目の前の自分の爪、被弾方向の表示、速報テロップ、被害総額の表示。
