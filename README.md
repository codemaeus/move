# Pixel Scenery

ブラウザで手続き生成するピクセルアートの景色アニメーション集です。どれも HTML ファイルを開くだけで動き、GIF 書き出しと動画録画ができます。

| ファイル | 内容 |
| --- | --- |
| `index.html` | 夜のドライブ（後部座席の窓から） |
| `train.html` | レトロ電車の車窓（朝・昼・夕・夜） |
| `sea.html` | 手漕ぎボートの海（朝・昼・夕・夜） |
| `diorama.html` | 夜の路地ジオラマ（アイソメトリック・lo-fi 音楽・雨あり／なし） |
| `lake.html` | ランタンの湖（縦長・オルゴールの子守歌・雨あり／なし） |
| `kaiju.html` | 怪獣大決戦 ボルガ 対 ジンライ（効果音・BGMつき） |

## Night Drive（index.html）

夜のドライブ中に、後部座席の窓から見える景色をブラウザで手続き生成するピクセルアートのアニメーションです。

- `index.html` をブラウザで開くだけで動きます（ビルドや外部ライブラリは不要）
- 描画解像度は 320×180。216色パレットと Bayer ディザで減色し、拡大表示しています
- 5層の視差スクロール（山並み / 遠景 / 中景 / 線路 / 近景）で、近いものほど速く流れます

## 景色（約 30〜60 秒ごとに移り変わる）
市街地・住宅街・田園・山道・トンネル・海沿い・大きな橋。
電柱と電線、自販機、カーブミラー、お地蔵さん、鳥居、電照菊のビニールハウス、灯台、漁船などが出てきます。

## イベント（ランダム）
鹿の群れの並走、キツネ、タヌキ、塀の上の猫、犬の散歩、自転車、ジョギング、
電車の追い越し／すれ違い、花火、流れ星、UFO、夏祭りの提灯、パトカー、夜間工事（誘導員）、雷。
画面の右側に、何が起きたかのログが出ます。

## 天気
自動（晴れ→雨→土砂降り→晴れの約90秒サイクル）/ 晴れ / 雨 / 嵐。
窓ガラスを後ろへ流れる水滴、雨筋、濡れた地面、雷。

## 書き出し
「GIFを作る」でブラウザ内で GIF を生成し、「動画を録画」で WebM を録画します。

`sample-country.gif`（田園・晴れ）と `sample-rain.gif`（住宅街・雨・夏祭り）がサンプルです。

## レトロ電車の車窓（train.html）
木の窓枠、白い枕カバーの青いボックスシート、網棚の麦わら帽子、揺れるつり革、天井の扇風機、窓際の冷凍みかんとラムネ。
田園・集落・鉄橋・海辺・山あいのトンネル・小さな町を走り、ときどき駅に停まります（駅名標つき）。
イベント: 踏切、犬の散歩、手を振る子ども、田んぼの農家さん、白サギ、自転車の並走、対向列車、夕方のカラス、飛行機雲、夜のホタル・花火・流れ星、釣り人。
時間帯は自動で朝→昼→夕→夜と巡ります（固定も可）。車体はレールの継ぎ目で跳ね、左右に揺れます。
「音を出す」でレールのガタンゴトン、モーター音、踏切（ドップラー効果つき）、警笛、発車メロディ、セミ・ヒグラシ・夜の虫の声が鳴ります（Web Audio で合成）。サンプル: `sample-train.gif`

## 手漕ぎボートの海（sea.html）
船首から見た一人称視点。オールで漕ぐと進み、止めると波に揺られて漂います。
イベント: 空き缶・手紙入りの瓶が流れてくる、トビウオ、カモメ（船首にとまることも）、漁船の釣り、遠くの島の焚き火、イルカ、クジラの潮吹き、クラゲ、ウミガメ、フェリー、飛行機雲、流れ星。
夜はイカ釣り漁船の漁り火、灯台、オールで光る夜光虫。サンプル: `sample-sea.gif`

## 怪獣大決戦（kaiju.html）
溶岩怪獣ボルガ（火炎放射・尻尾・マグマノヴァ）と雷獣ジンライ（剛腕パンチ・投げ・ビル投げ・雷撃ビーム・天雷招来）が夜の市街地で自動バトル。
ヒットストップ、画面の揺れ、白フラッシュ、反転インパクトフレーム、擬音テキスト、必殺技カットイン、倒壊するビル、戦闘機・戦車・報道ヘリ。
HP バー、ラウンド制、被害総額カウンター。効果音と太鼓の BGM は Web Audio で合成。サンプル: `sample-kaiju.gif`

## 夜の路地ジオラマ（diorama.html）
宙に浮かぶアイソメトリックの小さな夜の路地。アパート、ラーメン屋（提灯・のれん・ネオン・風鈴）、自販機、街灯、神社、水路と小さな滝、桜ならぬ電飾の木。
雨あり／なし／自動。雨は屋根や地面に当たってはね、水たまりと水路に波紋が広がる。晴れの夜は月・星・ホタル。
イベント: 傘の人、猫、出前のバイク、高架の電車、ベランダで一服、自販機で買う人、ラーメン屋の客、窓明かり、風鈴、流れ星、遠くの花火、雷。
音楽: lo-fi ヒップホップを Web Audio で生成（エレピのコード進行、ベース、スウィングしたドラム、メロディ、テープの揺れ、レコードのノイズ）。雨音・虫の声・効果音つき。サンプル: `sample-diorama.gif`

## ランタンの湖（lake.html）
縦長 180×320。天の川と三日月の夜、湖に浮かぶいかだの上の木の家。水面には空・家・ボート・丸太が波で揺れながら映り込む。
登場するのはオリジナルの動物たち（ランタンを持つハリネズミ、ボートで釣るカエル、望遠鏡のネコ、屋根のフクロウ）。
イベント: 流れ星、灯籠流し、跳ねる魚、釣り、フクロウの飛行、カモの親子、岸の鹿、オーロラ、紙の舟、手紙入りの瓶、窓明かり、雷（雨）。
音楽: 3 拍子のオルゴール・ハープ・パッドの子守歌を毎回生成（残響つき）。湖の水音、雨音、虫とカエル、フクロウや水鳥の声。サンプル: `sample-lake.gif`
